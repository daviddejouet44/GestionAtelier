# Kanban

Le Kanban permet de suivre les jobs par étape de production.

## Vue opérateur

- La barre de filtre Kanban inclut **Vue opérateur**.
- Sélectionnez un opérateur pour n'afficher que ses cartes.
- Le bouton **Réinitialiser** remet la vue sur tous les opérateurs.

## Affichage des colonnes

- Le bouton **Agrandir** d'une colonne permet de focaliser une étape.
- Les actions de cartes restent disponibles selon vos droits et le paramétrage de la colonne.
